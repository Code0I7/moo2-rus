## Почему не «СУО»

Для `Dauntless Guidance System` рассматривался вариант `СУО «Неустрашимый»`,
но аббревиатуру пришлось бы отдельно пояснять. Вместо неё взято
`Наведение «Неустрашимый»` — 170 px при бюджете 215 px, понятно без сносок.
Тот же принцип везде: сначала пробуем сказать короче обычными словами,
аббревиатуру вводим только если иначе не влезает.

Сокращения в таблицах справки выбраны так, чтобы уложиться в те же колонки,
что и английский оригинал: позиции колонок заданы кодом `\x07X<число>.`
прямо внутри строки, и сдвигать их нельзя без пересчёта всей таблицы.

## Экран новой игры и справочник

Подписи на экране новой игры зашиты в патч 1.50 строками фиксированной длины,
заменить их можно только на более короткие:

| Оригинал | Русский | Байт |
|---|---|---|
| Small / Medium / Large / Cluster / Huge | Малая / Средн. / Круп. / Скопл. / Огр. | 5/6/5/7/4 |
| Pre-warp / Average / Post-warp / Advanced | Доварп. / Средний / Постварп. / Развитый | 8/7/9/8 |
| N Players | N игрока, N игроков | 9 |
| RP / BC / FP / PR | ОН / КР / ЕД / ПР (очки науки, кредиты, единицы пищи, производство) | 2 |

В колонке «Как это?» справочника помещается около 150 px шрифтом 3, поэтому
список пунктов набран короткими формами («Новая колония», «Сбить комету»),
а полные заголовки остаются на самих страницах справки.

## Итерация 3: единые термины и короткие названия

Двухбуквенные коды модификаций выше сверены с тем, что реально стоит в
`TECHNAME.LBX` (раньше таблица расходилась с файлом: ПРО/ТУ/БР/РАЗД/НИ/ПЕР).
В тексте справки модификации перечисляются теми же словами, что и в списке
проектирования: «тяжёлая установка, точечная оборона, непрерывное…».

Сокращения, которые понадобились, чтобы названия влезли в список «Обзора
технологий» (176 px шрифтом 2) и в его заголовок (слово не шире 174 px
шрифтом 4 — длиннее движок режет посреди слова):

| Сокращение | Полностью | Где |
|---|---|---|
| Подпростр. телепорт / связь | подпространственный телепорт / связь | технологии, спецмодули |
| Доп. топливные баки | дополнительные топливные баки | технологии, спецмодули |
| Отсек тяж. истребителя | отсек тяжёлого истребителя | технологии |
| Св.бедн / Св.бог. | сверхбедная / сверхбогатая (U-Poor / U-Rich) | краткие метки минералов |

Остальные длинные названия заменены обычными словами без сокращений:
Гиперсвязь, Энергофокус, Робозавод, Портал измерений, Рассеиватель варпа,
Компрессор пространства, Двигатель на антиматерии, Торпеда/Бомба из
антиматерии, Импульсная ионная пушка, Нейтрализатор/Стабилизатор инерции,
Наведение «Отважный», Андроид-фермер/-рабочий/-учёный. Проверка —
`python tools/terms.py` (термины) и `tools/wrap.py` (переносы).
