# Как помочь проекту

**Русский** | [English](CONTRIBUTING-en.md)

## Сообщить об ошибке

Лучший вклад — скриншот. Откройте [issue](../../issues/new/choose), выберите
«Ошибка в тексте» или «Предложение по переводу».

## Исправить перевод

1. Положите клон репозитория в папку игры (`<игра>/moo2-rus`), установите
   Python 3.8+.
2. `python make.py build` — извлечь английский текст из игры в `text/` и
   собрать перевод.
3. Найдите запись: `python tools/show.py HELP` показывает id, лимит и текст.
4. Исправьте строку в `tr/<ФАЙЛ>*.jsonl` (или `python tools/settr.py <ФАЙЛ> fix.jsonl`).
5. `python make.py install`, проверьте в игре.
6. `python make.py check` — должно быть 0 потерянных маркеров, 0 пропавших
   строк и 0 непомещающихся текстов.

Правила: термины одинаковы везде (`tools/terms.py`), сокращения — только
если иначе не помещается ([список](docs/ABBREVIATIONS.md)), маркеры
подстановки (невидимые байты 0x80–0x95) не терять. Подробности —
[техническая документация](docs/DEVELOPMENT.md).

## Pull request

- один PR — одно исправление
- в описании — что исправлено и скриншот до/после, если менялся текст на экране;
- файлы игры (`*.LBX`, `*.EXE`, содержимое `text/` и `backup/`) не добавлять.
