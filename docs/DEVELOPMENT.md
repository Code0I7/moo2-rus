## Обзор

Перевод ставится как мод 1.50 (`150/mods/rus`, конфиг `RUS.CFG`) плюс:

- 12 LBX-файлов в корне игры, для которых у патча нет параметра конфига
  (оригиналы сохраняются в `backup/root/`);
- обратимая правка `ORION150.EXE` (оригинал — `backup/ORION150.EXE.orig`).

Файлов игры в репозитории нет. `make.py` извлекает английский текст из
установленной игры в `text/`, накладывает перевод из `tr/` и собирает
русские LBX из тех же оригинальных файлов. Весь конвейер воспроизводим:
повторная сборка даёт побайтно те же файлы.

Основной мод — **1.50 improved**: у него свои английские `HELP`, `TECHDESC`,
`HERODATA` и `KENTEXT` (изменённые числа, без устаревших цен расовых черт),
поэтому `dump_all.py` берёт их из `150/mods/150i/lbx/`.

## Конвейер сборки

```
dump_all.py → text/*.json (en) → apply_tr.py (+ tr/*.jsonl) → text/*.json (en+ru)
mkcyr.py → FONTS.LBX, IFONTS.LBX
build.py → 150/mods/rus/lbx/*.LBX
install.py → RUS.CFG, cfg/EXTRA.CFG, 12 LBX в корне, enable RUS
patchexe.py → ORION150.EXE
verify.py, markers.py → проверки
```

Порядок файлов перевода для одного LBX: `<FILE>.auto.jsonl` (транслитерация),
`<FILE>.jsonl`, `<FILE>.N.jsonl`, `<FILE>.fix.jsonl` — последний побеждает.
Многоязычные файлы (`TECHNAME`, `KENTEXT`, `JIMTEXT`, `COUNCMSG`, …) хранят
копию каждой строки на пять языков игры; переводится английская, остальные
копируются (`FANOUT`, `GROUP_FANOUT`, `BLOCK_FANOUT`, `SUB_FANOUT` в
`apply_tr.py`), поэтому игра показывает русский при любом `language.ini`.

## Правки ORION150.EXE

Все правки в `tools/patchexe.py`, обратимы (`patchexe.py revert`).
Линейный адрес → смещение в файле: `addr + 0x9569E`. Модуль патча 1.50
дописан после LE-образа и адресуется смещением в файле. Имена функций —
из таблицы символов, которую оставил в EXE патч 1.50 (`tools/syms.py`).

| # | Где | Проблема | Правка |
|---|---|---|---|
| 1 | `Print_Clipped_Character_` 0x112629, `Print_Character_To_Bitmap_` 0x11308c | `cmp eax,0x80`: коды выше 0x7F молча пропускаются — кириллица занимает место, но не рисуется | `cmp eax,0x100` |
| 2 | `Print_Clipped_Letter_` 0x112861/0x1128c5/0x11292a и его двойник для битмапов 0x113262/0x1132c6/0x113337 | смещение глифа читается как **знаковое** 16-битное (`movsx`); шрифты с кириллицей выходят за 0x8000, указатель уходит в минус — мусор над картинкой в «Обзоре технологий» и в «Статистике рас» | `mov reg, dword` + `nop` (та же длина). Расширять само чтение смещения (0x11282e/0x11322f) нельзя — игра падает; поэтому область глифов держится меньше 64 КБ (см. [Шрифты](#шрифты)) |
| 3 | `Set_Font_` 0x1107d0, `Set_Font_Solid_` 0x1108e1, `Set_Remap_Font_Style_` 0x110a34 | таблицы шрифта копируются циклом `i < 0xff`: символ 255 (CP1251 «я») не переносится и берёт глиф другого шрифта | предел `0x100` |
| 4 | сегмент данных | форматы и единицы (`%s (%d EP)`, `%d BC`, `RP`, звезда `Orion`) | замена строк той же или меньшей длины |
| 5 | пул строк модуля 1.50 | подписи экрана новой игры, шаблоны расовых черт (`$V$% Growth`), сообщения флота | замена не длиннее оригинала; строки лежат вплотную и адресуются по отдельности, отсюда сокращения `Огр.`, `Круп.` |

## Шрифты

- Запись 0 `FONTS.LBX`/`IFONTS.LBX`: 6 шрифтов; таблицы ширин `0x059C + i*0x100`,
  таблицы смещений глифов `0x0B9C + i*0x400` (dword), высоты `0x056C`,
  данные глифов с `0x239C`. Интервал между буквами — `SPACING` в `width.py`.
- У глифа нет длины: движок декодирует ровно `height` строк. Поэтому
  одинаковые глифы можно хранить одной копией — так `moo2font.build()`
  укладывает всю область глифов в 64 КБ (правка 2), а `mkcyr.py` отказывается
  собирать шрифт, если лимит превышен.
- Кириллица генерируется по рецептам из штрихов шрифта (`mkcyr.py`);
  совпадающие с латиницей буквы копируются. Дорисованы также «», – и — (в
  исходных шрифтах 0x96/0x97 пусты — каждое тире печаталось пустотой).
- Рецепты проверяются во всех 12 шрифтах (`preview_font.py`): ошибки видны
  только в мелких кеглях (л как п, ы как «оı», щ как ц, У как Y).

## Ограничения данных

- Патч 1.50 проверяет размер записи каждого LBX: пулы строк (ESTRINGS
  21000 Б, HESTRNGS 13521 Б, RSTRING0 6500 Б, MAINTEXT 14×600 Б) **нельзя
  увеличивать**; `build.py` печатает OVERFLOW.
- В режиме `fields` ёмкость строки — до следующего ненулевого байта записи;
  «хвосты» после NUL в полях имён ограничивают длину.
- Байты 0x80–0x95 — маркеры подстановки (правитель, раса, число). В тексте
  они невидимы, их легко потерять; `markers.py` сверяет наборы, допустимые
  пропуски (артикли, английское множественное число) — `DROPPABLE`.
  По той же причине в переводе нельзя использовать «…» (0x85).
- Перекрёстная автоподстановка одинаковых фраз между файлами работает только
  для текста хотя бы с тремя буквами: однобуквенные записи — горячие клавиши
  и служебные байты, их перезапись ломала данные.
- `install.py` подменяет файлы в корне, поэтому `dump_all.py` и `build.py`
  читают оригиналы из `backup/root/`, а не установленную русскую копию;
  `verify.py` ловит этот класс ошибок.
- Лаунчер не декодирует `mod_name`/`mod_desc` (показывает сырые байты), поэтому
  они латиницей; всё, что печатает игра, — в `cfg/EXTRA.CFG` в CP1251, во
  вложенной папке (Лаунчер считает модом любой `*.CFG` в папке мода).

## Размеры текстовых окон

Игра рисует в 640×480, DOSBox лишь масштабирует кадр, поэтому бюджеты в
пикселях абсолютны. Измерено по скриншотам (`wrap.py`, таблица `BOX`):

| Окно | Шрифт | Ширина | Строк |
|---|---|---|---|
| Обзор технологий: описание | 2 | 174 px | 11 |
| Обзор технологий: список | 2 | 176 px | 1 |
| Обзор технологий: заголовок | 4 | 176 px, слово ≤ 174 px (длиннее режется посередине) | 2 |
| Справочник: страница | 4 | 384 px | 18 |
| Справочник: колонка «Как это?» | 3 | ~150 px | 1 |
| Планеты: колонка размера | 2 | ~60 px | 1 |

## Рабочий цикл

```bash
python make.py build                 # извлечь, наложить перевод, собрать
python tools/show.py ESTRINGS        # строки файла: id, лимит, текст
python tools/settr.py HELP fix.jsonl # заменить перевод записей на месте
python make.py install               # установить в игру
python make.py check                 # маркеры, наличие строк, термины, переносы
```

Запуск игры для проверки (порядок конфигов важен):

```bash
DOSBOX/DOSBox.exe -conf 150/dosbox-150.conf -conf 150/dosbox.conf
```

`tools/run.ps1` запускает то же с `dosbox-test.conf` (`output=surface`: при
`ddraw` SDL читает мышь через DirectInput и игнорирует отправленные окну
сообщения), дальше `click.ps1 -Game X Y` и `shot.ps1` или `dbx.py`.

## Соглашения перевода

- Кодировка CP1251; управляющие байты игры (0x01–0x1F, 0x80–0x95, 0x9E)
  проходят насквозь. `%s`, `%d`, `\n` сохраняются в том же порядке.
- Термины едины во всём переводе (`terms.py`): грузовозы (freighters) и
  транспорт (troop transport), пища, точечная оборона, климат
  прилагательными (Земная, Болотная), Низкая/Обычная/Высокая G.
- Сокращения — только если иначе не помещается; список — [ABBREVIATIONS.md](ABBREVIATIONS.md).
- Имена собственные транслитерируются (`translit.py` → `tr/*.auto.jsonl`,
  файл перезаписывается); ручные правки — в обычном `<FILE>.jsonl`.

## Сборка релиза

`.github/workflows/release.yml` на теге `v*` собирает `moo2-rus.exe`
(PyInstaller из `make.py`), упаковывает его с `tr/` и `cfg/` в
`moo2-rus-<тег>.zip` и создаёт черновик релиза. Файлов игры в архиве нет:
exe собирает перевод из копии игры пользователя.

## Что не сделано

- Кнопки. Главная панель — `BUFFER0.LBX`: надписи
  впечатаны в кадр 0, элементы 1–10 — подсветка и нажатое состояние.
  Кодек картинок готов (`lbximg.py`, round-trip на 6489 картинках без
  расхождений); программный шрифт для надписей не дотянул по качеству.
- Скрипты горячих клавиш 1.50 (`150/scripts/main/MAIN*.LUA`) и сообщение мода
  Mirror.
- Экраны середины и конца партии проверены выборочно.
