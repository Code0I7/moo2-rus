# История изменений

## 0.9.0-beta — первая публичная версия

* Переведён весь текст игры (около 12 500 строк) для патча 1.50.26; справка,
  описания технологий и KENTEXT взяты из мода «1.50 improved», поэтому числа
  совпадают с его правилами.
* Кириллица во всех шрифтах FONTS.LBX и IFONTS.LBX.
* Правки `ORION150.EXE` (обратимые): вывод символов с кодом выше 0x80,
  беззнаковое смещение глифа (мусор над картинкой в «Обзоре технологий»), 
  строки патча 1.50 (экран новой игры, расовые черты,
  единицы, сообщения флота), звезда «Орион».
* Все описания «Обзора технологий» и страницы справочника укладываются в
  свои окна; названия технологий помещаются в список и заголовок.
* Единая терминология (проверка `tools/terms.py`): грузовозы и транспорт,
  пища, точечная оборона, климат, минералы, гравитация.
* Установщик `moo2-rus.exe` для игроков и `make.py` для
  сборки из исходников; файлов игры в релизе нет.
* Удаление оставляет в `150/mods/rus/lbx` оригинальные английские файлы:
  сохранения, начатые с переводом, без них не загружаются.
* Не переведены кнопки.
